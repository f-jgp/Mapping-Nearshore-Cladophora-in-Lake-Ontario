**python function instructions**


**clip.py**<br>
clip the original Sentinel-2 image base on ROI geojson file.

**index.py**<br>
calculate and create NDVI, FAI, NDAVI, and SABI image by clipped Sentinel-2 image

**color.py**<br>
color the NDVI, FAI, NDAVI, and SABI image

**footprint.py**<br>
download the footprint and quicklook of Sentinel-2 base on the api of Copernicus Data Space Ecosystem  

**quicklookclip.py**<br>
clip the quicklook base on the calculation of footprint and ROI coordinate.
